# Resources

A reference library for **reusable technical knowledge**: programming concepts, system design, testing methods, databases, performance, security, DevOps, embedded systems, and anything else worth learning.

- Organize by subjects **only as needed**, not by creating dozens of empty directories.
- Distinguish examples and assumptions from verified conclusions.
- Link to primary documentation and include review dates for version-sensitive claims.
- Put prescriptive, reusable project guidance in [the playbook](../playbook/README.md), not in raw study notes.

See [knowledge conventions](../docs/knowledge-conventions.md).
